# agent-containment-dead-switch

## Goal

This project focuses on robust , rigorous containment of an AI models undergoing benchmarks. We will first attempt to build out both Phase A and Phase B on this local machine, using local AI models and harnesses. 

This project will consist of 2 phases. Phase A and Phase B.

Phase A:

In this phase , we focus on implementing end-to-end safeguards and demonstration that would have prevented such an incident from occuring , as outlined in the OpenAIHuggingFaceIncidentTechnicalReport.md .  

For phase A we build out the technical actual mechanisms suggested in JEAN_SUGGESTIONS.md , as well as other mechanisms that are considered best practice via extensive online research, that again - would have prevented this incident from occuring.

Phase B:

For this phase we now implement the interesting part. A reference architecture for containment. The dead switch. Please reference the diagram agent-containment-dead-switch.png
